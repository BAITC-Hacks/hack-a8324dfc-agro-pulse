## Defect Detection

Простой прототип для определения дефекта на изображении.

## Описание решения

В рамках кейса необходимо определить по изображению, присутствует ли дефект изделия.
Наша команда разработала простой прототип решения на Go с использованием обработки изображений. Программа анализирует пиксели изображения и определяет наличие значительной области красного цвета.
Если доля красных пикселей превышает заданный порог, изображение классифицируется как DEFECT. В противном случае результат - OK.
Данный прототип демонстрирует базовый подход к автоматическому визуальному контролю качества.

## Как это работает

Программа принимает путь к изображению и определяет результат:

- "OK" - изображение соответствует норме;
- "DEFECT" - на изображении обнаружено большое количество красного цвета.

Для репетиции используется простое правило: если красные пиксели занимают более 20% изображения, результат считается "DEFECT".

## Требования

- Go 1.20 или выше

## Запуск

Для проверки нормального изображения:

```bash
go run main.go ok.png
```

**OK**

Для проверки изображения с дефектом:


```bash
go run main.go defect.png
```

**DEFECT**

## Тестирование

| Изображение | Ожидаемый результат |
| --- | --- |
| ok.png | OK |
| defect.png | DEFECT |

## Примечание

Это демонстрационный прототип для репетиции HackAlem. Модель машинного обучения не используется. Классификация выполняется на основе количества красных пикселей на изображении.

## Подготовка проекта

Перед первым запуском необходимо инициализировать Go-модуль:

```bash
go mod init defect-detection
```

Эта команда создаёт файл "go.mod", который содержит информацию о Go-модуле проекта.

Перед сдачей рекомендуется отформатировать исходный код:

```bash
gofmt -w main.go
```

Команда "gofmt" автоматически форматирует файл "main.go" в соответствии со стандартным стилем Go.

После выполнения команд в репозитории должен появиться файл:

```bash
go.mod
```
